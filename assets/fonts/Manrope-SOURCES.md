# Manrope

The unmodified Manrope variable font (weights 200–800), from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope), is bundled locally for the observatory clock and temperature. It is licensed under the SIL Open Font License 1.1; see `Manrope-OFL.txt`. No font service is contacted at runtime.

Source file: https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/Manrope%5Bwght%5D.ttf
