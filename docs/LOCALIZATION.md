# Interface localization

The renderer supports `en`, `it`, `fr`, `de`, `es` and `ja`. English is the default. The language is stored separately in `atomic.language` and does not change station encoding, time zones, watch profiles or personal content.

All 84 offline manual screenshots use Rainbow and Pulse Sync, with the sidebar expanded to show the active menu and its section. The documentation-only capture layout preserves the normal content width beside the navigation. `npm run capture:guide` regenerates all six language sets with illustrative data in a temporary profile, without running test suites. Capture-time clocks remain inside the bundled ISS snapshot's validity window.

`src/locales/messages.mjs` exports the merged five-language catalog, keyed by original English text. Light Travel and Reception Lab messages live in `src/locales/light-travel.mjs` and `src/locales/reception-lab.mjs` and are merged there. Watch Accuracy messages are in `src/locales/watch-accuracy.mjs`, including graph labels, validation, reference provenance and observation events. Thematic sidebar labels are in `src/locales/sidebar.mjs`. Full manual prose is in `src/guide-data.mjs` with translations in `src/locales/guide.mjs`; every purpose, body paragraph, example and note must have all five translations. Localized UI screenshots are in `assets/guide/{language}/` and are regenerated by `npm run capture:guide` using a temporary sample profile. Expanded journey narratives and captions are in `src/locales/time-machine-expansion.mjs`. Add every new interface message in all five languages. Preserve every numbered interpolation field (`{0}`, `{1}`, etc.); use `t('Message {0}', value)` instead of concatenating translated grammar. Keep units, station identifiers, DOM IDs, reference keys and stored enum values stable.

`src/i18n.mjs` binds static text nodes and accessible attributes once before views are created. It never scans user-generated DOM or observes all mutations. Dynamic views call `t()` while rendering and subscribe to `onLanguageChange()` to refresh their own text without resetting forms or audio. Use the locale-aware date/number helpers for display. Protocol calculations and SVG numeric coordinates keep their original formats. Only app-generated retained messages may use `localizeStoredMessage()`; never apply it to personal names or notes.

Native menu translations are in `electron/main.cjs`; the preload exposes a validated language IPC request. Japanese font fallback is local; its source and license are documented in [THIRD_PARTY.md](THIRD_PARTY.md).

Run `npm run test:guide` to assert all 85 prose passages against their full translations and load every localized screenshot in Electron. Run `npm run test:accuracy` for populated watch journals, manual/NTP provenance, GET links, exports, six languages and fifteen themes. Run `npm test` to check interpolation coverage and all 96 journey narratives. Run `npm run test:languages` for the real Electron UI across all six languages, all sections, valid ISS data, German/Japanese journeys, fifteen themes, persistence, localized search, native menus, personal-text preservation and uninterrupted muted transmission. It writes screenshots and layout/residual-English reports to `artifacts/languages/`. All desktop tests use temporary profiles.
